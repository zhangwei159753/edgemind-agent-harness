# EdgeMind

> 面向个人长期任务的本地优先 Agent Harness，将任务状态、记忆治理、知识检索与受控工具执行组合为可恢复、可追踪的运行流程。

[GitHub](https://github.com/zhangwei159753/edgemind-agent-harness)

## 项目背景

普通对话式 Agent 通常围绕单次问答构建：任务中断后难以恢复，跨会话信息缺少治理，工具调用也不易审计。EdgeMind 聚焦这些运行时问题，提供任务检查点、分层记忆、检索证据、工具授权和离线质量评估。

EdgeMind 是一个可本地运行和扩展的个人工程项目。模型 API、语音识别、RAG 与 MCP 服务按需配置；未配置的外部服务不会被当作可用能力。

## 技术栈

- **运行时与界面：** Python 3.11、Gradio
- **模型：** DeepSeek API（OpenAI 兼容接口）
- **状态与检索：** SQLite、FTS5；可选本地向量检索适配器
- **工具扩展：** MCP Python SDK、内置天气与网页搜索工具
- **语音：** 可选 faster-whisper 本地语音识别
- **质量评估：** pytest、离线 fixture 数据集、版本化策略评测

## 核心设计

### 可恢复的长程任务

任务、阶段、检查点与执行事件分开记录。用户可以查看任务进度，并从已保存的检查点继续执行；会话记录不直接等同于任务状态。

### 有治理边界的记忆

记忆按工作、情景、语义和程序四层组织。系统支持记忆候选、确认与淘汰，并通过实体关系构建轻量记忆图；图检索限制扩展深度和结果数量。

### 有预算约束的多 Agent 协作

路由器根据任务复杂度选择单 Agent 或受限协作流程。多 Agent 流程包含规划、专业角色执行、结果汇总和审查；候选分支、执行步数与模型调用预算均有上限。系统记录可检查的决策摘要，不向用户暴露或依赖隐藏思维链。

### 可评估的经验闭环

用户反馈和任务结果可以生成版本化策略候选。候选策略先在固定 fixture 集上与基线比较，通过门槛后再由操作者显式启用；评测报告保留数据集版本、策略版本和结果，支持回滚。单次成功不会自动变成永久经验。

### 检索、工具与多模态输入

个人知识库检索结果为回答提供证据。内置工具覆盖天气与网页搜索，MCP 可连接额外工具服务。工具执行受允许列表、参数校验和必要的用户确认约束；不开放任意 Shell 或 Python 执行。

文本与图片通过配置的模型接口处理；音频可通过 faster-whisper 转为文本，再进入任务流程。图片理解取决于模型端点的多模态能力，语音识别取决于本地模型及运行环境。

## 运行流程

```text
输入 → 加载任务/检查点与相关记忆、知识 → 选择单 Agent 或受限协作
     → 执行模型与获准工具 → 结果审查 → 返回回答并记录事件
     → 用户反馈/离线评测 → 人工启用通过门槛的策略版本
```

## 快速开始

### 环境要求

- Python 3.11
- [uv](https://docs.astral.sh/uv/) 包管理器
- DeepSeek API Key（使用在线模型时需要）

### 安装与启动

```powershell
git clone https://github.com/zhangwei159753/edgemind-agent-harness.git
cd edgemind-agent-harness
uv sync
Copy-Item .env.example .env
```

在 `.env` 中配置模型密钥：

```dotenv
DEEPSEEK_API_KEY=your_api_key
```

```powershell
python myapp.py
```

打开 `http://127.0.0.1:7860`。请勿将包含真实密钥的 `.env` 文件提交到版本库。

## 可选能力

| 能力 | 安装或配置 | 说明 |
| --- | --- | --- |
| 图片理解 | 配置支持视觉输入的模型端点 | 图片会发送到所配置的模型；单文件限制 20 MiB，原始图片不作为长期记忆保存。 |
| 本地语音识别 | `uv sync --extra audio` | 使用 faster-whisper；首次运行可能需要下载模型文件。 |
| MCP 工具 | `uv sync --extra mcp` | 在 MCP 配置中登记服务；有副作用的工具可要求用户确认。 |
| 本地 RAG | `uv sync --extra rag` | 按项目 RAG 配置接入语料与检索模型；未准备语料时不会产生知识库证据。 |
| 网页搜索 | 配置 `BRAVE_SEARCH_API_KEY` | 通过 Brave Search API 获取网页结果；搜索结果是来源线索，不代表可信事实。 |
| 天气查询 | 无需独立密钥 | 使用 Open-Meteo；可用性取决于网络连接及服务状态。 |

更多环境变量、MCP 服务格式和运行选项见 `.env.example` 与 `docs/`。

## 评测与验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests\edgemind -q
```

Agent 质量页面可使用 `tests/data/agent_multi_agent_v1.jsonl` 对执行模式进行离线对比。fixture 评测用于检查固定场景下的路由、工具、证据和策略行为，不代表线上模型效果或生产 SLA。RAG 检索评估入口及语料格式见 `docs/` 中的相关说明。

## 数据、安全与限制

- 默认面向本机开发使用；对外部署前应增加身份认证、访问控制、HTTPS、速率限制和密钥管理。
- API Key 应通过环境变量或本地 `.env` 提供。调用模型时，用户输入及必要上下文会发送到配置的模型服务，请根据服务条款处理敏感数据。
- 任务、记忆和评测状态保存在本地 SQLite 数据中；请自行管理备份与清理。
- MCP 服务有其自身权限边界。连接前应审查服务来源、工具描述和参数，并对写入或外部副作用操作启用确认。
- 经验闭环提供候选评测和人工启用机制，不表示 Agent 会无监督修改模型权重或自动保证正确性。
- 离线 fixture 可用于回归检查；真实 API 的输出、延迟和费用受模型服务、网络与提示词影响。
