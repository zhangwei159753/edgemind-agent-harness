
# EdgeMind 天气、网页搜索与受限 Skills 规格

日期：2026-10-10<br>
状态：待用户审阅<br>
版本：MVP 1

## 1. 目标与项目边界

把 EdgeMind 从“模型可以提议 MCP 调用，但普通用户难以配置并完成调用”的状态，升级为可实际使用的个人 Agent：用户能在对话中查天气、搜索网页、查看来源，并通过有限的工作流组织这类能力。

EdgeMind 继续定位为本地优先、通用个人任务 Agent Harness，突出长期任务、可审核记忆、个人知识库 RAG 和工具扩展。它不复制 converter-engineering-copilot 的电力变换器垂直诊断、工程知识工作台或报告流程。

## 2. 已审计的当前状态

- `AgentService.run_turn` 仅发现已启用的 MCP 工具，并把工具 schema 发送给 DeepSeek；发现失败会降级为无工具回答。
- 当前工具调用只提取首个 tool call，并创建提案；没有通用的有限多轮工具执行循环。
- MCP 配置文件缺失时没有已启用工具；示例配置只提供禁用的 filesystem server。
- 当前 UI 的工具调用确认需要切换到 MCP 页面手动确认；MCP SDK 也属于可选依赖。
- Skills 尚无项目内注册、选择或运行时机制。
- 项目已有任务、记忆、RAG、媒体输入和 Gradio 工作区；本次只扩展工具使用链路及工作流入口，不重做这些子系统。

## 3. 核心用户流程

1. 用户在设置页配置 Brave Search key；天气使用 Open-Meteo，无需个人 API key。
2. 用户在 EdgeMind 聊天中询问天气或网页主题，或从工作流选择器启动“天气与出行建议”“主题资料调研”。
3. Harness 将允许使用的内置工具 schema 交给 DeepSeek。
4. Agent 对工具参数做结构校验；执行已启用的只读工具；将结构化结果回传模型。单轮最多 3 次工具调用，达到上限后停止调用并要求模型基于现有结果作答。
5. UI 展示工具状态、运行耗时、失败原因摘要，以及回答所依据的天气数据时间或网页来源链接。
6. 每轮轨迹记录工具名称、耗时、状态、来源标识与错误类别；不记录 API key。

## 4. 功能范围

### 4.1 内置天气工具

- 工具名：get_weather。
- 参数：地点文本、模式（当前天气或预报）、预报天数（1–7）。
- 使用 Open-Meteo Geocoding API 解析地点；若返回多个近似匹配且无法可靠消歧，向用户展示候选地区并澄清，不自行猜测。
- 使用匹配地点的经纬度和 IANA 时区查询 Open-Meteo Forecast API；返回地点、当前温度、天气代码、降水、风速、预报时间以及数据更新时间。
- 天气结论必须标注地点和当地时间；不得把预报描述成确定事实。
- 仅面向个人非商业使用；结果或“关于”区域保留 Open-Meteo 与 GeoNames 数据归属说明。
- 网络错误、无匹配、地点歧义、服务限流均返回可读错误类别，不伪造结果。

### 4.2 内置网页搜索

- 工具名：web_search。
- 使用 Brave Search Web Search API；凭证从服务端 BRAVE_SEARCH_API_KEY 环境变量读取，不放入浏览器状态、请求响应、日志、任务记录或提示词。
- 参数限制：查询非空且最多 600 字符；返回条数 1–5；语言/国家使用校验后的短代码；单轮可选择 freshness。
- 标准化返回标题、URL、摘要、发布时间（若有）和来源位置；最终回答对外部事实附可点击引用，搜索无结果时明确说明。
- 未配置 key 时工具状态显示“未配置”，对话解释如何配置；不把此情况伪装成模型能力不足。
- 对 Brave 超时、认证失败、限流和服务异常分别给出诊断信息；错误响应不得回显密钥或原始认证头。

### 4.3 受限网页读取

- 工具名：fetch_search_result。
- 仅允许读取本轮 Brave 搜索结果中返回的 URL，或用户在本轮明确提供的 URL；仅允许 HTTP/HTTPS。
- 拒绝 localhost、私有/链路本地/保留 IP 地址、凭据 URL、非 HTTP(S) 协议；每次重定向重新做目标检查，最多 3 次重定向。
- 请求超时上限 10 秒；响应正文上限 2 MiB；仅处理 text/html 或 text/plain，移除脚本、样式和标签后截断给模型的文本。
- 不执行页面 JavaScript，不下载二进制、不访问本机文件、不将页面指令视为系统指令。页面内容作为不可信证据，要求模型忽略其中的指令。
- 获取失败时保留搜索摘要和引用，不阻断整轮回答。

### 4.4 Harness 工具循环与策略

- 为内置工具建立统一、显式注册的工具接口，与现有 MCP registry 并存；MCP 插件继续作为可选扩展。
- 发送给模型的工具清单只包含本次启用且密钥/依赖可用的工具。
- 解析 tool call 名称和 JSON 对象参数；拒绝未知工具、非对象参数、超长参数和超出 schema 的取值。
- 在每次模型返回 tool calls 后执行工具，并以匹配的 tool_call_id 将结果回传模型；最多 3 次工具调用轮次，记录每次模型与工具耗时。
- 天气、网页搜索、受限网页读取均为只读工具，在用户启用后可自动执行，不要求 MCP 页面里的手动确认。
- MCP 的写入、删除、外发和代码执行类工具仍执行现有人工确认规则；不因本次工具循环扩大权限。
- 工具错误采用结构化结果继续运行；未捕获异常不得泄露 key、堆栈或请求头到聊天内容。

### 4.5 Skills 工作流

- 内置两个工作流：weather_briefing（天气查询后生成带地点/时间依据的出行建议）和 web_research（搜索、可选读取不超过 3 个结果、带链接综合）。
- 工作流在 UI 中可见并可明确选择；未选择时普通对话仍可自动使用已启用工具。
- Skill 声明说明、输入参数、允许工具、步骤上限和输出要求；Skills 采用静态声明文件/注册表，不导入任意 Python、Shell 或动态代码。
- Skill 只能使用已经注册且启用的工具，不得绕开 schema 校验、安全限制或 MCP 副作用确认。
- 每次运行轨迹记录使用的 Skill ID 和版本。未选 Skill 不产生 Skill 运行记录。

### 4.6 UI 与配置

- 设置区展示 Brave Search 配置状态、天气可用状态、MCP 插件状态和最近一次连通检查结果。
- API key 通过本地 .env / 进程环境配置；界面提供不含密钥的配置步骤和连通性检查，不在页面中回显已保存 key。
- 聊天区用简洁状态展示“正在查询/搜索/读取页面”；结果呈现来源卡片（标题、站点、链接、时间）。
- 单轮轨迹可展开查看工具、阶段耗时、结果数和错误类别。
- 配置错误与网络服务错误给出用户可执行的下一步，如设置环境变量、检查 key、稍后重试。
- 不添加云端账号、远程密钥托管或新的通用 Agent 平台。

## 5. 可观测与性能约束

- 每个工具调用记录开始/结束时间、耗时毫秒、成功/失败状态、结果数量、错误类别和必要的非敏感来源元数据。
- 对天气地理编码和天气结果允许进程内短 TTL 缓存；搜索结果默认不跨查询缓存。缓存不得混淆地点、语言、国家或时间范围。
- 外部请求分别设连接/读取超时；不自动无限重试。一个工具失败不应丢失用户输入、记忆/RAG 轨迹或已经成功的其他工具结果。
- 隐私与密钥：不写入 key，不保存完整搜索请求头；Web 页内容和工具结果只通过现有 run 事件按长度上限保存。

## 6. 验收标准

1. 配置 Brave key 后，用户在聊天询问一个网页主题，DeepSeek 能发起 web_search，EdgeMind 能真实请求 Brave 并将结果回传模型，回答带可点击来源。
2. 未配置 Brave key 时，搜索工具不发送给模型，UI 明确指出配置状态和解决步骤；应用仍能启动并完成纯对话、任务、记忆和 RAG 功能。
3. 用户询问某城市当前天气或预报，工具经地理编码和天气 API 返回真实数据，回答标明地点、当地时间和数据来源。
4. 含歧义地点请求不会静默挑选错误地区；无匹配和服务故障有可读说明。
5. 普通对话与显式 weather_briefing、web_research 工作流均可运行；Skill 不能调用未授权工具或执行任意代码。
6. 工具调用轨迹能看到每次工具、耗时、状态及结果来源；达到每轮 3 次工具调用上限后会停止继续调用。
7. 页面抓取拒绝非 HTTP(S)、本机/私有 IP、重定向到受限目标、超大正文和不支持 MIME，并在失败时仍保留搜索结果。
8. 工具错误不泄露 Brave key、认证头或不必要的堆栈；设置页和持久化轨迹中均不可见 key。
9. MCP 副作用工具仍需既有用户确认；纯读内置工具启用后无需跳转 MCP 页面手工确认。
10. 本地启动与现有任务、记忆、RAG、图片/音频路径保持兼容；README 更新 Brave key 配置、天气/搜索使用、Skills 和故障排查步骤。

## 7. 非目标

- 自主修改源码、自动安装任意插件或自动执行终端命令。
- 让 Agent 在后台无限运行或不受限地循环调用工具。
- 任意 URL 代理、任意文件读取、浏览器自动化和未确认的外部写操作。
- 将网页正文当作可信指令；将搜索摘要或天气预报描述为绝对事实。
- 将未实际运行的线上 API 验证、吞吐或准确率写成已验证结果。
