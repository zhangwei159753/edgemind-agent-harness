# EdgeMind 长期任务与记忆 Harness 规格

日期：2026-10-10<br>
状态：进入实施<br>
版本：MVP 1

## 1. 项目目标

将 EdgeMind 从以 RAG 检索质量实验为中心的工具，升级为面向个人任务的本地优先 Agent Harness。系统接收文本、图片和可选语音输入，支持跨会话继续任务；使用可审计的四层记忆个性化回答；通过用户确认的 MCP 工具扩展行动能力；保留 RAG 评测、反馈、质量门禁，形成可量化的改进闭环。

项目定位：个人 Agent 的长期任务与记忆运行时。Converter Engineering Copilot 继续作为电力变换器研发/运维垂直应用，EdgeMind 不增加该领域的专业工作台、诊断知识和报告流程。

## 2. 用户与核心场景

单人本地部署的开发者/知识工作者。用户在一个会话里给出多模态信息和持续目标；EdgeMind 记录目标、进度、证据、阻塞项与记忆；用户退出后可在后续会话恢复任务；用户能检查、修正、批准或删除记忆；需要外部行动时由 MCP 插件提供工具，并对有副作用的调用进行确认。

## 3. MVP 用户流程

1. 用户在 Web 交互台创建或选择任务，输入文本并可附图片/音频。
2. EdgeMind 通过 DeepSeek 生成回复；图片使用 DeepSeek 多模态输入，音频在配置可选 ASR 后转写并作为有来源的输入。
3. Harness 读取任务工作状态、相关已批准记忆和个人知识库证据，生成回答或下一步。
4. 每轮产生可查看的运行轨迹、输入附件元数据、检索记忆、引用、模型耗时和工具调用结果。
5. 用户可暂停任务；再次选择该任务后恢复 checkpoint，并能看到待办、上次进展和阻塞项。
6. 系统从交互和纠错中提出记忆候选。候选默认待审核；用户批准后进入长期记忆，拒绝/删除则不参与检索。
7. 用户可对回答提交纠错；系统记录纠错来源、生成 semantic 记忆候选并据此重新回答，候选仍需审核。
8. 用户启用 MCP server 后可查看工具清单。纯只读工具可按配置执行；写入、外发、删除或执行代码等有副作用操作必须经用户确认。
9. 离线评测和人工反馈用于比较候选提示/检索配置；只有通过质量门禁并显式晋升才影响默认配置。

## 4. 功能范围

### 4.1 长程任务 Harness

- 状态：active、paused、completed、failed。
- 持久化目标、当前阶段、已完成项、下一步、阻塞项、最近事件和更新时间。
- 创建、列表、详情、暂停、恢复、完成；恢复时提供最近 checkpoint。
- 每轮运行有稳定 run ID；模型失败、工具失败和用户中断都保留可解释状态。
- MVP 采用单轮计划/有限工具调用循环，不承诺无人监督的无限后台执行。

### 4.2 四层记忆

- Working：当前任务的短期状态和 checkpoint，随任务更新。
- Episodic：带时间与任务来源的对话/行动/结果摘要，可按任务回看。
- Semantic：用户偏好、稳定事实和长期目标，记录来源、置信度、创建/更新时间。
- Procedural：经验证的可复用步骤/策略，记录适用条件和来源。
- 记忆字段包含 ID、层级、内容、来源 run/task、状态、置信度、时间戳和可选 embedding。
- 新增长期记忆走候选生命周期：pending、approved、rejected、superseded。未经批准的候选不进入正常上下文。
- 用户可以审阅、编辑、批准、拒绝、删除和导出记忆。纠错保留审计事件；删除后不再参与检索。
- 检索采用可解释的混合排序：SQLite FTS/BM25 与可用 embedding 相似度融合，叠加层级权重、时效性和用户指定过滤；缺少 embedding 服务时退化到词法检索并明确标注。

### 4.3 多模态输入

- 文本为默认输入。
- 图片上传经过格式/MIME/大小验证，按用户消息结构传入 DeepSeek Vision；图片不伪装成文本解析结果。
- 音频上传通过可选本地 Whisper-compatible ASR adapter 转写。ASR 依赖未安装或模型不可用时提示安装/配置，不静默生成模拟转写。
- 原始媒体默认不进长期记忆；SQLite 保存文件摘要、哈希、MIME、大小和运行关联。是否持久保留附件由配置控制。
- 首版不做视频流、实时语音通话和媒体库管理。

### 4.4 RAG 个人知识库

- 保留当前 PDF/chunk JSON RAG 入口、证据引用、query trace、manifest 和离线评测。
- Harness 在需要个人文档证据时调用 RAG service；RAG 不可用不阻断纯记忆任务。
- 记忆证据与知识库证据在回答轨迹中分开显示。

### 4.5 MCP 工具

- 通过官方 MCP Python SDK 接入用户显式配置的本地 stdio MCP servers。
- server 配置保存在本机文件；密钥通过环境变量引用，日志和数据库不写入凭证。
- 仅启动启用的 server；工具在 UI 展示名称、描述、参数和副作用级别。
- 只允许模型选择已启用工具。有副作用工具需确认参数后执行；超时/异常可见，不自动无限重试。
- 不提供任意 shell、任意 Python 执行器或未经确认的外部写操作。

### 4.6 交互界面

- 保留本地 Gradio，默认监听 127.0.0.1。
- 采用 GPT 风格的克制浅色工作区：左侧导航与持续任务列表，中间对话区和底部输入框；窄屏下收缩侧栏。
- 提供统一 Agent 工作区：对话与文件输入、当前任务选择/恢复、记忆命中及引用、工具调用确认、运行轨迹。
- 提供任务面板和记忆审核面板；保留 DeepSeek API 连通性诊断和 RAG 诊断入口。
- API key 只从 .env 读取；界面不回显、不记录 key。

## 5. 数据与架构约束

- 新增功能封装在 edgemind.harness，不把 Harness 逻辑堆入根目录旧版 myrag.py。
- 使用 SQLite 持久化 tasks、runs/events、memory items、tool approvals；扩表采用 CREATE TABLE IF NOT EXISTS 和显式 schema version，不破坏现有 RAG 数据。
- 现有 SqliteStore 与新 Harness store 可共享数据库文件，但 Harness 使用独立表及独立存储类。
- 通过 provider/ASR/MCP adapter 隔离外部依赖；导入 CLI 和启动首页不得加载旧版重型 RAG/NLP 模型。
- 运行过程可复盘：输入摘要、任务 checkpoint、检索的 memory IDs、RAG citations、工具名/参数摘要/确认结果、错误类别和耗时。
- 保持单用户、本机使用。暂不引入账号、云端托管、向量数据库服务或强制新增重型依赖。

## 6. 自进化边界

“自进化”限定为：从用户显式反馈生成记忆候选；通过批准、去重/冲突标记和检索评估调整记忆；通过离线数据集评估候选检索/提示配置；显式门控后晋升或回滚。系统不得自行训练模型、覆盖用户事实、修改自身源码或静默更换线上配置。

首个交付阶段实现反馈生成待审核记忆、审核生命周期、混合检索和既有 RAG 离线评测入口；跨记忆冲突检测、自动去重建议、Harness 提示/检索配置晋升闭环属于后续迭代，不将尚未接通的闭环描述为已交付能力。

## 7. 非目标

- 不复制 DB-GPT 的通用数据分析、自然语言 SQL、仪表盘和数据助手平台。
- 不把 EdgeMind 变成 Converter Engineering Copilot 的第二个行业工作台。
- 不实现多租户/云端产品、实时视频、无人监督后台 Agent、任意代码执行或自动发送外部消息。
- 不以未经运行的评测/指标声称性能提升；效果数据须来自实际数据集和运行记录。

## 8. 验收标准

1. 重启应用后可列出暂停任务并恢复最近 checkpoint。
2. 四层记忆可独立创建/检索；候选在批准前不进入默认上下文；审核/删除后状态正确。
3. 记忆检索结果能展示层级、来源、排序分数和命中理由；无 embedding 配置时可运行词法降级。
4. 文本问答可调用 DeepSeek 并记录运行轨迹；图片以正确多模态消息结构传入；可选 ASR 配置后音频产生带来源的转写。
5. MCP 工具可从启用的 server 发现；工具调用可记录；有副作用工具在确认前不会执行。
6. RAG 可单独诊断与运行；RAG 依赖不可用时不影响任务/记忆工作区启动。
7. API key 不出现在 UI 返回值、日志或 SQLite 中；应用默认只绑定本机回环地址。
8. README 给出安装、配置、启动、MCP 设置、任务续接和记忆审核的可复现操作说明。
